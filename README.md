# sela — سيلا

**نقطة بيع ذكية بتعرف بصري محلي — تعمل بلا إنترنت 100%**

<div dir="rtl">

سيلا هو نظام نقاط بيع (POS) متكامل لأندرويد يعمل **داخل جهازك بالكامل** — بياناتك كلها محلية بلا خادم وبلا إنترنت. صوّر منتجك مرة واحدة من ثلاث زوايا، ثم وجّه الكاميرا نحوه عند البيع ليُضاف للسلة تلقائياً.

التطبيق يعمل بنظام **اشتراك مدفوع** (شهري/سنوي) يُفعَّل بمفتاح من إدارة sela — انظر «نظام الاشتراك» أدناه.

> الإصدار الحالي: **v10.0.0** — محرك تعرّف بصري جديد (EfficientNet-B0، محلي 100%): أسرع في الحالة اليومية (استدلال واحد للمنتج المفرد) وأدق بكثير في تمييز المتشابهات، مع كشف **عدة منتجات في صورة واحدة** وقراءة كل واحد على حدة وإضافته للسلة تلقائياً. إصلاح ترقيم الفواتير بعد الاسترجاع من نسخة احتياطية (يكمل من آخر فاتورة مسجلة)، زر التصوير في نافذة المسح المزدوج دائم الظهور (تبديل المحرك بلمسة)، ورسالة نفاد الكمية داخل شاشة المسح لكل المسارات.

## المزايا

| المجال | التفاصيل |
|--------|----------|
| التعرف البصري | **EfficientNet-B0** (v10) محلياً على الجهاز (TFLite) — تطابق كوسيني مع حماية من المتشابهات، **كشف متعدد المنتجات في صورة واحدة** (نوافذ 3×3 + عدّ وحدات)، مسار سريع باستدلال واحد للمنتج المفرد، 3 بصمات/منتج (أمامية/خلفية/جانبية) + مرايا |
| البيع | شبكة منتجات بلمسة واحدة + مسح (باركود ML Kit مدمج أو بصري أو كلاهما) + بحث فوري، تبديل مفرق/جملة فوري، خصومات، منع البيع بأكثر من المخزون |
| المحاسبة | فواتير متسلسلة، COGS وصافي ربح لكل فاتورة، تقارير (اليوم/أمس/7 أيام/الشهر)، ساعات الذروة، الأفضل مبيعاً |
| الطباعة | طابعة حرارية بلوتوث (ESC/POS) — 58/80مم، عربي CP1256/CP864، قص تلقائي |
| الوحدات | وحدات يعرّفها المستخدم (كرتونة = 24 قطعة، كيلو، علبة) بأسعار مفرق/جملة لكل وحدة وباركود وحدة — الخصم من المخزون بالقطعة تلقائياً |
| الجرد | جلسات جرد كاملة بلقطة نظام، عدّ سريع، زر مطابق، ملخص فروقات، تعديل مخزون معامَلي، تقرير كامل + CSV |
| المخزون | إدارة كاملة مع صور مصغرة وتصنيفات يديرها المستخدم، تنبيهات نفاد/انخفاض + إشعارات نظام أندرويد |
| التصدير | CSV/Excel محلياً إلى مجلد التنزيلات + نسخة احتياطية كاملة |

## البنية التقنية

- **React Native 0.74** Bare CLI (بدون Expo) + TypeScript صارم — معمارية Services / Stores / Screens / Components / Repos
- **الكاميرا**: وحدة CameraX أصلية مكتوبة خصيصاً للتطبيق (Kotlin) — باركود ML Kit مدمج يعمل دون إنترنت، التقاط صور للتعرف البصري، عدّاد حماية (watchdog) يمنع أي تعليق أو شاشة سوداء
- **خط أنابيب الرؤية**: `takePhoto` → وحدة Kotlin أصلية لفك الترميز (BitmapFactory + قص مركزي + تصغير) → تطبيع → TFLite `runSync` → تطابق كوسيني في JS — **بدون Frame Processors** (أكثر موثوقية على كل الأجهزة)
- **قاعدة البيانات**: op-sqlite (JSI) + ترحيلات إصدارية + WAL — جداول: categories, products, product_embeddings, sales, sale_items
- **التنقل**: React Navigation (native-stack + bottom-tabs) مع دعم زر الرجوع الفيزيائي وانتقالات أصلية RTL
- **وحدات Kotlin أصلية**: SelaCamera (CameraX + ML Kit)، ThermalPrinter (SPP/ESC-POS + طباعة شعار المتجر GS v 0)، ImageDecoder، SelaNotifications، ImagePicker، PlatformUtils (معرّف الجهاز + وقت النظام الرتيب للتراخيص)
- **واجهة**: نظام تصميم موثق في [`design.md`](./design.md) — خط Tajawal، أيقونات SVG مخصصة، رسوم بيانية SVG مخصصة، ErrorBoundary شامل (لا شاشات سوداء)

## نظام الاشتراك والتفعيل

التطبيق **مقفل** حتى تفعيل اشتراك مدفوع (شهري أو سنوي) بمفتاح على الشكل `SELA-XXXXX-XXXXX-XXX` تشتريه من إدارة sela:

- **التفعيل مرة واحدة** عبر الإنترنت، ثم يعمل التطبيق دون إنترنت مع فترة سماح تصل إلى 10 أيام.
- **الترخيص موقّع رقمياً (Ed25519)** — أي تلاعب ببياناته على الجهاز يبطله فوراً.
- **مضاد الغش**: مدة الاشتراك تُحسب من وقت السيرفر مثبّتةً على العدّاد الرتيب للنظام (`elapsedRealtime`) — إرجاع ساعة الهاتف للخلف لا يُعيد الاشتراك ويُسجَّل كمحاولة غش، وبعد 5 محاولات أو 10 أيام دون اتصال بالسيرفر يُقفل التطبيق حتى تحقق ناجح واحد.
- **من لوحة الإعدادات**: حالة الاشتراك، الخطة، المتبقي، معرّف الجهاز، إعادة تحقق فورية، نقل الاشتراك لجهاز جديد (إلغاء الربط)، وبيانات التواصل مع الإدارة.

سيرفر التفعيل (يستضيه المالك على Coolify): [sela-license-server](../sela-license-server) — لوحة إدارة عربية لإنشاء المفاتيح وتمديدها وإيقافها ومتابعة الأجهزة.

## التحميل

حمّل أحدث `app-release.apk` من [صفحة الإصدارات](../../releases) وثبّته مباشرة على جهاز أندرويد (7.0+، ARM).

## البناء من المصدر

```bash
npm ci
cd android && ./gradlew assembleRelease
# APK: android/app/build/outputs/apk/release/app-release.apk
```

المتطلبات: Node 20، JDK 17، Android SDK (compileSdk 34، NDK 26.1).

## هيكل المشروع

```
src/
├── components/     # Icon (SVG) · ui kit · ScannerCamera · ErrorBoundary · charts
├── core/           # theme (design tokens) · config · types · format · diagnostics
├── database/       # connection (migrations) · repositories
├── navigation/     # RootNavigator (stack + tabs)
├── native/         # Typed bridge للوحدات الكوتلن
├── screens/        # 10 شاشات: الرئيسية، POS، المخزون، المنتج، التقارير، الإعدادات، الطابعة، الإشعارات، التشخيص
├── services/       # VisionRecognition · Invoice · Report · Export · StockAlerts · ThermalPrinter
└── stores/         # zustand: cart · catalog · settings · printer · notifications · toast
```
